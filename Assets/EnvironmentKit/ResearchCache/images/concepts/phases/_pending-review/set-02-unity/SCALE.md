# Unity terrain scale (Environment Kit defaults)

| Item | Meters |
|------|--------|
| **One terrain tile** | 220 × 200 (height) × 220 (`WorldGenerationRequest.SurfaceExtentMeters`) |
| **Play disk** | 3×3 tiles → **660 m × 660 m** |
| **FullWorld grid** | 9×9 terrains → **~1980 m × 1980 m** |
| **South foothill annex** | 3 tiles at z=-2 row (660 m wide strip south of play) |
| **South peak annex** | 3 tiles at z=-3 row |

Scene captures must show **Terrain** objects at this scale (not miniature dioramas).
